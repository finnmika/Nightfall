Nightfall
=========

Clientseitiger Minecraft-Utility-Client für Fabric (Bewegungs-, Kampf-, ESP- und Weltwerkzeuge).

- Version: 0.5.18
- Minecraft: 1.21.11
- Mod-Loader: Fabric Loader >= 0.18.1
- Java: >= 21
- Benötigt: Fabric API

Installation
------------

1. Fabric für Minecraft 1.21.11 installieren.
2. Fabric API in den mods-Ordner legen.
3. nightfall-0_5_18.jar in den mods-Ordner legen.
4. Minecraft starten.

Die jar enthält SeedCrackerX bereits (eingebettet), das muss nicht extra installiert werden.
